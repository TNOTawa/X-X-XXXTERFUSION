# Toy部署与真机检查

## 准备

先按README用自己有权使用的素材生成 `dist/toy/` 或相应ZIP。仓库不提供原曲媒体或可直接上传的成品。安装官方 [Toy skill/CLI](https://github.com/bilibili/toy)，命令参数以当次 `toy --help-json` 为准，不在代码中保存登录凭据。

官方文档：
- https://www.bilibili.com/toy/publish/guide
- https://www.bilibili.com/toy/publish/sdk

## 首次发布

1. 上传Toy内容，先检查预览，再由作者明确确认提交审核。CLI使用 `--json` 且不加 `--yes` 时仅生成预览；没有作者确认不要加 `--yes`。
2. 可以先用链接可见范围测试，建议启用仅App访问；审核通过不代表已验证视频桥。
3. 上传自己有权发布的配套成片，保持素材时间轴不变。待稿件过审后，把自己的视频BV号绑定到自己的Toy。
4. 最新版B站App → 配套视频 → Toy入口 → 半屏。独立打开Toy预览、手机浏览器或PC调试不能替代这一步。

更新已有作品时使用原Toy的“更新”流程，保留Toy ID、slug和原视频绑定，不要为了换包新建作品。新版本过审后完全退出旧半屏再重新打开。

## 音画职责

原生视频提供PV、谱面提示及无应答伴奏。Toy只播放有效命中的鼓点；误触和Miss不补音。选择难度、重开及校准通过SDK定位视频；Promise<void>不是实际起播回执，适配器等待状态通知。

`setPlayerState.muted`控制的是视频，不是Toy面板的独立禁音。进入后先在Toy右上角开启面板声音；鼓点音量条仅调WebAudio鼓点，不改变视频或系统音量。

## 验收清单

- 无第二个HTML播放器，无完整伴奏的网页下载请求；视频和鼓点不双重播放整曲。
- iOS/Android首次击打时网页音效不会抢占或暂停原生视频音频。
- 简单18、普通66、硬核162拍与提前首拍正常；双指与快速连打不被误防抖。
- 初次起播/缓冲恢复的小幅时钟修正不误入练习；明显拖动进度和变速仍排除排名。
- 鼓点默认150%，菜单与游玩音量条同步，0–300%修改可在本机恢复；平台禁音仍需手动开启。
- 校准为单次30拍连续窗口，可中途加入，不必先休息两拍；系统自动排除适应样本。样本不足、前后漂移或噪声过大不覆盖旧值。
- 周期节拍有半拍歧义：大延迟蓝牙可先手动填写粗略补偿再校准。校准使用原始误差，不累加旧补偿。
- 暂停/缓冲/后台切换停止判定和鼓点尾音；恢复后可继续。
- 结算后音乐继续，1.2秒内重开、换难度及提交被锁定；异步榜单不提前解锁，末尾连点不丢成绩。
- 排行榜仅在结算读取、用户明确操作时提交；未登录、拒绝授权、断网和限流都应提示，避免连续重试。
- 小屏/安全区/半屏尺寸变化正常。旧App、外部浏览器或缺少视频宿主时，开始和校准被禁用并提示换环境。

## 可选浏览器回归

浏览器测试只连接专门为项目启动的无头浏览器/CDP9228实例，不要使用日常浏览器或真实账号。完整本地素材已准备好且本地服务器运行时，可依次执行：

```sh
node tests/browser-host.mjs
node tests/browser-calibration.mjs
node tests/browser-smoke.mjs
```

这些测试验证页面/接口时序，不等于真实App音频混音或硬件延迟验证。源码公开CI不运行这些依赖私有素材的浏览器验收。

## 已知边界

无服务端验谱，不宣称竞技级反作弊。公共SDK未提供Toy面板禁音的代开接口。资源暂未做contenthash；榜单无自动轮询/自动重试，遇307044请稍后再试，不连续点击。媒体再分发权限由使用者自行确认，代码许可证不覆盖媒体。
